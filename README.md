## Описание
ИСКРА — это мини-приложение внутри платформы MAX, которое помогает пользователям находить новые знакомства и интересные мероприятия на основе общих увлечений. Бот в MAX используется для умных рассылок и уведомлений.

**Фронтенд проекта находится в отдельном репозитории:** [ISKRA-FRONTEND](https://github.com/Ijne/ISKRA-FRONTEND)

## Функциональность

### Для пользователей Mini App:
- **Регистрация и аутентификация** через платформу MAX.
- **Создание и редактирование профиля** с указанием интересов, хобби и предпочтений.
- **Поиск и рекомендации** мероприятий с Timepad API на основе интересов пользователя.
- **Поиск и рекомендации** других пользователей для знакомств на основе графа интересов (Memgraph).
- **Просмотр профилей** и отправка лайков.

### Для Бота:
- **Получение контактов** заинтересовавших пользователей (vk id).

## Технологический стек

### Backend:
- **Язык:** Go
- **Роутинг:** Chi
- **Базы данных:** PostgreSQL (основные данные), Memgraph (графовая БД для рекомендаций)
- **Контейнеризация:** Docker, Docker Compose

### Frontend (отдельный репозиторий):
- **Языки:** Чистый HTML, CSS, JavaScript
- **Хостинг:** GitHub Pages

### Внешние API:
- **MAX Bot API:** для работы с ботом и мини-аппом
- **Timepad API:** для получения данных о мероприятиях

## Архитектура

Проект состоит из следующих основных компонентов:

1.  **Mini App (Frontend):** статический сайт, хостится на GitHub Pages. Общается с бэкендом по REST API.
2.  **Backend (Go Application):**
    - `miniapp` — обрабатывает запросы от фронтенда (профили, мероприятия, лайки).
    - `bot` — обрабатывает long polling от платформы MAX и управляет рассылками.
    - `shared` — общие модули (модели, утилиты, работа с БД).
    - `main` — файлы для запуска приложения.
3.  **Базы данных:**
    - **PostgreSQL:** хранит пользователей, мероприятия, лайки.
    - **Memgraph:** хранит граф интересов для построения рекомендаций.
4.  **Внешние сервисы:**
    - **MAX Platform:** предоставляет инфраструктуру для бота и мини-аппа.
    - **Timepad API:** источник данных о мероприятиях.

## Запуск проекта
Проект настроен для деплоя с использованием Docker и Docker Compose.

### Предварительные требования
- Установленные [Docker](https://docs.docker.com/get-docker/) и [Docker Compose](https://docs.docker.com/compose/install/).

### Инструкция:
1. **Версия для Linux/macOS (не проверял).**
   Выполните:
   ```bash
   git clone https://github.com/Ijne/ISKRA.git
   cd ISKRA
   git checkout dev
   chmod +x setup.sh
   ./setup.sh
   ```
2. **Версия для Windows.**
   Выполните:
   ```powershell
   git clone https://github.com/Ijne/ISKRA.git
   cd ISKRA
   git checkout dev
   # В PowerShell (от имени администратора если нужно)
   .\setup.ps1

3. **Или попросту.**
   Выполните:
   ```powershell
   git clone https://github.com/Ijne/ISKRA.git
   cd ISKRA
   git checkout dev
   docker-compose up
   ```
## Послесловие
Запустив проект можно переходить в мессенджер MAX и проверять работоспособность @t21_hakaton_bot. Скрипты для заполнения тестовыми пользователями лежат в папке init-scripts (если вам вдруг захочется повыполнять вручную).
